COMMONSLENS

Advanced Wikimedia Commons search

CommonsLens helps researchers, educators, journalists, designers, and developers search and download reusable images, SVGs, audio, video, and documents from Wikimedia Commons.

Advanced media search

  • Search images, SVG and vector graphics, audio, video, PDFs, DjVu files, and other documents.
  • Use direct file autocomplete, multi-term OR queries with +, or search entirely from filters.
  • Filter 17 exact formats, sort six ways, load results continuously, remove individual filter chips, and inspect the generated CirrusSearch query.
  • Share a complete text, filter, and asset-view state as a clean URL.

Semantic, rights, and technical filters

  • Include or exclude Wikidata depicts entities and arbitrary property-value statements with AND or OR logic.
  • Include or exclude categories and templates, combine categories with intersection or union, and recursively search subcategories.
  • Filter CC0, CC BY 4.0, CC BY-SA 4.0, Public Domain, attribution requirement, Quality Images, Valued Images, and Featured Pictures.
  • Filter language, content model, creation and edit dates, dimensions, file size, color depth, coordinates, radius, or proximity to a named place.

Map, directories, and connected discovery

  • Browse paginated Commons categories and templates or search Wikidata subject Q-codes.
  • Search the map by point, radius, named place, or bounding box and plot an existing search as clustered thumbnail markers.
  • Use street, satellite, or hybrid layers with zoom, rotation, camera fitting, and responsive result panes.
  • Browse author upload portfolios, related files, nearby geotagged media, and global Wikimedia usage.

Media inspection and responsible reuse

  • View images, vectors, audio, video, and supported PDFs natively with fallbacks for other documents.
  • Inspect creator, uploader, descriptions, dates, dimensions, categories, assessments, coordinates, and Structured Data on Commons.
  • Review license, attribution, credit, usage terms, copyright status, permission, restrictions, and incomplete-rights warnings.
  • Copy ready-to-use plain-text attribution, HTML, or WikiText with links to the original source and full license.

Downloads and research exports

  • Download original files or available 640px, 1280px, and 1920px derivatives.
  • Select result subsets and export full-resolution or web-optimized ZIP archives with progress, cancellation, and large-batch splitting.
  • Receive a CSV metadata manifest containing source links, descriptions, technical fields, rights, attribution, dates, classifications, and coordinates.
  • Export pipeline results as CSV, JSON, original ZIPs, optimized ZIPs, previews, or a complete Search result collection.

Visual Wikimedia data pipelines

  • Connect 31 source, filter, set-operation, transform, preview, and export nodes on a no-code canvas.
  • Source media from text, categories, subjects, statements, templates, locations, authors, or related files.
  • Union, intersect, subtract, deduplicate, sort, sample, select fields, and enrich results with structured data or global usage.
  • Preview capped runs, autosave graphs in IndexedDB, reopen saved workflows, import or export JSON, and cache Wikimedia queries.

Free and open source

CommonsLens is powered by the Wikimedia CirrusSearch API and Wikidata, providing a fast, high-performance visual interface to run complex metadata queries against Wikimedia Commons without writing a query by hand. It's free, open source under the Apache License 2.0, and built for researchers, journalists, educators, and developers who need properly-licensed media.
