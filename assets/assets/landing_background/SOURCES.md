# CommonsLens landing background media

The files in this directory are optimized animated GIF derivatives prepared
from the following Wikimedia Commons GIFs. The visual source remains the
original Commons file; the GIF conversion keeps the landing page bundle
small enough for browser delivery. Rotation durations are taken from the source
GIF metadata so each scene advances after one complete source loop.
