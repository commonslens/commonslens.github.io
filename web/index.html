CommonsLens: Wikimedia Commons Discovery Engine

An advanced visual discovery engine for researchers, designers, and developers to explore Wikimedia Commons — the world's largest library of free-to-use images, video, audio, and documents.

Features

  • Semantic subject search ("depicts"): find media depicting a specific subject via Wikidata, with multi-select include and exclude filtering.
  • Category search: filter and exclude by Wikimedia Commons category, including deep-category mode.
  • License filtering: CC0, CC BY 4.0, CC BY-SA 4.0, and Public Domain.
  • Quality assessment: Quality Images and Valued Images.
  • Geolocation search: find media near a given latitude and longitude.
  • Date filtering: creation date and last-edited date ranges.
  • File-type filtering: images, SVG/vector diagrams, audio, video, and documents.

About

CommonsLens is powered by the Wikimedia CirrusSearch API and Wikidata, providing a fast, high-performance visual interface to run complex metadata queries against Wikimedia Commons without writing a query by hand. It's free, open source, and built for researchers, journalists, educators, and developers who need properly-licensed media.
